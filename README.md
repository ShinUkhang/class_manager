## 🚀 빠른 시작 및 활용 가이드

### 1. 🖥️ 스마트 학급 대시보드 (`02_웹프로젝트/index.html`)
- **실행 방법**: 브라우저에서 `02_웹프로젝트/index.html`을 바로 열람하거나 웹 서버(Live Server 등)로 실행합니다.
- **주요 기능**:
  - 오늘의 시간표, 급식 메뉴 자동 조회
  - 학급 알림장 및 수행평가 일정 안내
  - 구글 스프레드시트 CSV 연동 실시간 데이터 업데이트
  - 생일 축하 인터랙션 및 외출증/확인증 발급 기능
- **디자인 체험**: `디자인_3종_비교체험_가이드.html`에서 다양한 테마(토스/노션/파스텔)를 미리 비교 체험할 수 있습니다.

### 2. 📓 음성인식 AI 실습 (`03_실습노트북/`)
- **Google Colab** 또는 **VS Code (Jupyter Extension)** 환경에서 `.ipynb` 파일을 엽니다.
  1. `01_음성인식_기초_소리의_파형과_원리.ipynb`: 소리의 디지털화, 파형 시각화, 주파수 분석 실습
  2. `02_음성인식_실전_AI_귀_만들기와_스마트_비서.ipynb`: 머신러닝 음성 분류 모델 학습 및 나만의 스마트 비서 제작

### 3. 📖 강의 교안 및 수업 지도안 (`01_교안및문서/`)
- 교사용 수업 지도안 및 학생용 인터랙티브 교재 웹페이지(`음성인식_인공지능_수업교재.html`)가 포함되어 있어 차시별 수업 진행에 바로 활용할 수 있습니다.
