소리가 글자가 되는 마법: 인공지능 음성인식(Speech AI)

LESSON 01 • 기초 개념 및 소리 시각화

컴퓨터는 귀도 없는데 어떻게 사람의 소리를 들을까?

우리가 말할 때 일어나는 공기의 떨림(진동)이 마이크를 거쳐 0과 1의 디지털 숫자로 변환되고, 인공지능이 이를 무지개 스펙트로그램(Spectrogram) 그림으로 바꾸어 읽어내는 신기한 원리를 체험해봅니다!

직접 만져보는 소리 실험실: 주파수 & 파형 시뮬레이터

슬라이더를 움직여 소리의 높낮이(주파수)와 크기(진폭)를 바꿔보세요!

실시간 파형 (Waveform): Sine Wave 440 Hz (라 음)
수학 공식: \( y = A \cdot \sin(2\pi f t) \) ● Web Audio API 활성화됨
주파수 (소리의 높낮이) 440 Hz
50Hz (초저음) 2,000Hz (고음)
진폭 (소리의 크기) 50 %

1. 진폭 (Amplitude) = 소리의 크기

파형의 높낮이 폭이 클수록 강한 에너지를 가지며 큰 소리(Big Volume)가 납니다. 컴퓨터는 이 값을 데시벨(dB)이나 0~1 사이의 숫자로 저장합니다.

2. 주파수 (Frequency) = 소리의 음정

1초 동안 공기가 진동하는 횟수(Hz)입니다. 횟수가 많을수록 얇고 높은 모기 소리(고주파), 횟수가 적을수록 굵고 낮은 덤프트럭 소리(저주파)가 됩니다.

3. 스펙트로그램 = AI가 보는 소리의 그림

파형만 봐서는 사람 말을 알 수 없습니다! 소리를 시간과 주파수의 2차원 무지개 그림(Spectrogram)으로 변환해야 AI가 글자로 읽어낼 수 있습니다.

01_음성인식_기초_소리의_파형과_원리.ipynb 
# 파이썬으로 440Hz 소리 만들고 재생하기
import numpy as np
import IPython.display as ipd

sampling_rate = 16000
duration = 2.0
t = np.linspace(0, duration, int(sampling_rate * duration), endpoint=False)

# 440Hz 사인파 소리 생성
sound_wave = 0.5 * np.sin(2 * np.pi * 440 * t)

# 노트북에서 바로 소리 듣기!
ipd.Audio(sound_wave, rate=sampling_rate)

# OpenAI Whisper로 음성을 한글 텍스트로 1초 만에 변환
import whisper

# 1. AI 모델 불러오기
model = whisper.load_model("base")

# 2. 내 목소리 파일 인식
result = model.transcribe("my_voice.wav", language="ko")

# 3. 인식 결과 출력
print("AI가 인식한 말:", result['text'])
